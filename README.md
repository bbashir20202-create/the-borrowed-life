# The Borrowed Life 🧬

> What if you could live one day as someone else?

This repository is a public archive of people who temporarily **borrowed someone else’s life** for 24 hours.

You choose a person — real or fictional, living or dead — and for one full day, you eat what they would eat, speak like them, make decisions like them, adopt their mindset, beliefs, and habits.

Then you write an honest report of what happened.

This is not cosplay.  
This is **empathy as an extreme sport**.

### How to Participate

1. Choose someone to borrow
2. Live one full day as them (as close as reasonably possible)
3. Write a raw, honest report
4. Submit it using the [template](./submission-template.md)

**Warning:** This project has been known to cause identity crises, sudden clarity, and uncontrollable laughter.
